# Desktop Companion Brain Sidecar

This process is started and supervised by the Rust desktop host. It owns the
conversation workflow and the Mem0 integration, but it has no permission to
control Windows, PMX bones, morph weights, or audio devices.

All dependencies are local-only:

- the HTTP server binds to `127.0.0.1`;
- every request requires the per-process token generated by Rust;
- LLM and embedding endpoints must resolve exclusively to loopback addresses;
- proxies, redirects, and Mem0 telemetry are disabled;
- SQLite, Qdrant local mode, and logs live below the Tauri app-data directory;
- missing local services make readiness fail instead of enabling a cloud fallback.

Create the debug environment from the repository root:

```powershell
uv sync --project brain-sidecar
```

Normally the process must not be started manually. `pnpm tauri dev` launches it.
